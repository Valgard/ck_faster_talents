# Faster Talents

Vanilla hands out one talent point every 5 skill levels — 25 for a maxed skill,
which is not enough to fill a single tree. This mod replaces that curve: a
point every 3 levels up to 60, then every 2 levels to 100, for **40 points** at
max. Enough to fill one tree completely.

Skill XP is multiplied as well (3× by default, switchable on its own), so the
points arrive sooner too.

It applies **retroactively** — load an existing character and its skills
immediately reflect what the new curve would have granted.

Uninstalling later is safe: vanilla's formula grants fewer points than you have
placed, and the game simply blocks further spending. Talents already placed
stay active.

Player skills only — pet talents are untouched, Faster Pet Talents does those.

## Settings

**Options → Mod settings** — on/off, plus the XP multiplier (off, 2×, 3×, 5×,
10×, 20×, 50×).

## Requirements

**Mod Settings Menu** and **CoreLib** — mod.io offers to install both when you
subscribe.

## Multiplayer

Install on both the client and the server.
