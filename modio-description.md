# Faster Talents

In vanilla Core Keeper, each skill earns one talent point every 5 levels,
plus a few at the maximum level — 25 points for a fully maxed skill. Faster
Talents replaces that with a quicker two-tier curve:

- One talent point every 3 skill levels, up to level 60
- One talent point every 2 skill levels, from 60 to 100
- 40 talent points for a maxed skill — enough to completely fill one talent
  tree

The "New talent point available!" popup and chime fire on every level that
grants a point, so you always know when you have earned one.

**Faster levelling, too:** the mod also multiplies all skill-XP gain (default
3×), so your skills — and the talent points they unlock — arrive sooner. A
separate, independently toggleable effect from the talent curve.

**Retroactive:** the faster rate applies to characters you already have —
load in and your skills immediately reflect the talent points they would
have earned under the new curve.

**Removing the mod:** if you spend the extra points and later uninstall,
vanilla's formula grants fewer points than you have placed. The game handles
this gracefully — it simply blocks further spending; talents you have
already placed stay active.

This mod changes player skill talents only — pet talents are untouched.

**Multiplayer:** install the mod on both the client and the server.
